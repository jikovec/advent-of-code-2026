# Benchmark records

Use `cargo aoc bench --day N --part P --format json` for structured timing. Record the actual revision, compiler, profile, CPU, sampling settings and dataset provenance with any public figures. Label Desktop and CI measurements explicitly. Compare matching sampling settings and environments.

Keep raw benchmark artifacts here in ignored storage. The generated README displays reviewed mean nanoseconds per part and derives the difference. Check metadata for private paths and identifiers and inspect recorded data before publishing any measurements. Keep private profiler and visual output in `profiles/` and `visualizations/`.
